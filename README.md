# 🥻 Indian Saree Pattern Classifier

An AI-powered web application that identifies the **pattern/style of an Indian saree from an uploaded image**.

The application uses a machine learning image classification model and provides predictions through an easy-to-use **Streamlit web interface**.

## 🚀 Live Demo

🔗 **[Saree Pattern Classifier – Live Web App](https://saree-pattern-classifier-wc3udy2vpu5orskmc4fsi4.streamlit.app/)**

## 📌 Features

* 🖼️ Upload a saree image
* 🤖 AI-based saree pattern classification
* 📊 Displays the predicted saree pattern
* ⚡ Fast and simple prediction
* 🌐 Interactive Streamlit interface
* 📱 Easy-to-use web application

## 🛠️ Technologies Used

* **Python**
* **Machine Learning / Deep Learning**
* **TensorFlow / Keras**
* **Streamlit**
* **NumPy**
* **Pillow**
* **Google Colab / Kaggle** for model development and training

## 🧠 How It Works

1. User uploads an image of an Indian saree.
2. The uploaded image is processed and resized.
3. The trained machine learning model analyzes the image.
4. The model predicts the saree pattern/class.
5. The predicted pattern is displayed on the Streamlit web application.

## ⚙️ Installation

### 1. Clone the repository

```bash
git clone https://github.com/YOUR-USERNAME/saree-pattern-classifier.git
```

### 2. Navigate to the project

```bash
cd saree-pattern-classifier
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Run the application

```bash
streamlit run app.py
```

The application will open in your browser.
